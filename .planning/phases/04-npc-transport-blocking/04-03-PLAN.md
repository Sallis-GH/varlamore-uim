<objective>
Add Dizana's Quiver unlock gate that restores charter ship access and removes Mysterious Old Man stand-ins once the player acquires the quiver (reward for beating the Fortis Colosseum).

Purpose: Varlamore-locked UIMs who complete the Colosseum earn the right to use charter ships for trade. This is a meaningful progression gate — the quiver represents a major Varlamore achievement. When unlocked: charter ship NPCs become visible (RenderCallback allows rendering), Mysterious Old Man RuneLiteObjects are deactivated, and charter ship menu clicks are allowed. When the quiver is removed: charter ships re-hide and Mysterious Old Man stand-ins reappear. Primio quetzal remains permanently blocked since it's a direct Varrock route with no Varlamore-internal value.

NPC-03, NPC-04, NPC-05 (fairy rings, spirit trees, gnome gliders) are trivially satisfied: none are accessible to Varlamore-locked UIMs. This plan carries those requirement IDs as their formal coverage point.

Output: Charter ship blocking dynamically responds to Dizana's Quiver ownership. RuneLiteObject stand-ins toggle with unlock state. Unlock detection via ItemContainerChanged (event-driven, no tick polling).
</objective>

public static boolean containsDizanasQuiver(ItemContainer container)

**Add imports to VarlamoreUimPlugin:**

- `import net.runelite.api.ItemContainer;`
- `import net.runelite.api.events.ItemContainerChanged;`

**Add ItemContainerChanged event handler:**
```java
@Subscribe
public void onItemContainerChanged(ItemContainerChanged event)
{
    if (npcTransportBlocker == null || !config.blockNpcTransport())
    {
        return;
    }

    int containerId = event.getContainerId();
    if (containerId == InventoryID.INVENTORY.getId() || containerId == InventoryID.EQUIPMENT.getId())
    {
        boolean nowUnlocked = checkDizanasQuiverOwned();
        if (nowUnlocked != npcTransportBlocker.isUnlocked())
        {
            npcTransportBlocker.setUnlocked(nowUnlocked);
            log.debug("Charter ship unlock state changed: {}", nowUnlocked);
        }
    }
}
```

**Add private helper method:**
```java
private boolean checkDizanasQuiverOwned()
{
    ItemContainer inventory = client.getItemContainer(InventoryID.INVENTORY);
    ItemContainer equipment = client.getItemContainer(InventoryID.EQUIPMENT);
    return NpcTransportBlocker.containsDizanasQuiver(inventory)
        || NpcTransportBlocker.containsDizanasQuiver(equipment);
}
```

**No explicit login check needed:**
`ItemContainerChanged` fires when the game loads inventory/equipment containers after login, which triggers the unlock check automatically. The default `unlocked=false` is safe — charter ships start blocked, then unlock if quiver is detected.

**Reset on shutdown:**
No extra action needed — `destroyStandInNpcs()` is already called in shutDown() (added in Plan 02), and the npcTransportBlocker object is discarded.
