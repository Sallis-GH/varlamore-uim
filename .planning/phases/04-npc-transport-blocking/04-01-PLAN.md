<objective>
Create the NpcTransportBlocker service that hides charter ship Trader Crewmember NPCs at all 3 Varlamore ports and blocks Primio quetzal interaction. Wire into the plugin with a config toggle.

Purpose: Prevent players from using NPC-based transport to leave Varlamore. Charter ship NPCs are hidden via RenderCallback (they become invisible and non-interactable). Primio quetzal is blocked via menu-click consumption with a chat message. This satisfies NPC-01 and NPC-02 (charter ships and ship NPCs).

Note on NPC-03, NPC-04, NPC-05 (fairy rings, spirit trees, gnome gliders): These are trivially satisfied because none are accessible to Varlamore-locked UIMs — all require quest completions outside Varlamore. No blocking code is needed.

Output: Working NPC transport blocking with config toggle, chat feedback for blocked interactions. Foundation for Plan 02 (Mysterious Old Man stand-in spawning) and Plan 03 (Dizana's Quiver unlock gate).
</objective>

  <name>Task 1: Create NpcTransportBlocker service with NPC hiding and interaction blocking</name>
  <files>src/main/java/com/varlamoreuim/npc/NpcTransportBlocker.java</files>
  <action>
Create `src/main/java/com/varlamoreuim/npc/NpcTransportBlocker.java` in a new `npc/` package.

**NPC ID constants:**
- `CHARTER_NPC_IDS`: `Set<Integer>` containing all Trader Crewmember IDs across 3 Varlamore ports: Sunset Coast (15510-15517), Aldarin (15518-15525), Fortis Cothon (15526-15533). Use `Set.of()` with all 24 IDs listed explicitly.
- `PRIMIO_NPC_ID`: `int` constant = 12889 (Civitas illa Fortis side, flies to Varrock).

**State fields:**
- `private boolean enabled = true` — controlled by plugin based on config toggle.
- `private boolean unlocked = false` — controlled by plugin based on Dizana's Quiver ownership (wired in Plan 03).
- Provide `setEnabled(boolean)` and `setUnlocked(boolean)` and `isUnlocked()` methods.

**RenderCallback (NPC hiding):**
- Create a `RenderCallback` field implementing `addEntity(Renderable renderable, boolean ui)`.
- If `!enabled || unlocked`, return `true` (show all NPCs).
- If `renderable instanceof NPC`, cast and check `CHARTER_NPC_IDS.contains(npc.getId())`. Return `false` to hide, `true` otherwise.
- Provide `public RenderCallback getRenderCallback()` getter so the plugin can register/unregister it.

**Primio quetzal blocking method:**
- `public boolean handlePrimioClick(MenuOptionClicked event, Client client, ChatMessageManager chatMessageManager)`:
  - If `!enabled`, return false.
  - Check menu action is NPC action: `NPC_FIRST_OPTION`, `NPC_SECOND_OPTION`, `NPC_THIRD_OPTION`, `NPC_FOURTH_OPTION`, `NPC_FIFTH_OPTION`.
  - Look up NPC via `client.getCachedNPCs()[event.getId()]` (NOT comparing event.getId() directly to NPC definition ID — event.getId() returns the NPC array index for NPC actions).
  - Bounds-check the index: `npcIndex >= 0 && npcIndex < npcs.length`.
  - If `npc != null && npc.getId() == PRIMIO_NPC_ID`, consume event and send chat message: "The bird doesn't seem interested in interacting with you." (per locked decision). Return true.
  - Otherwise return false.

**Charter ship menu blocking method:**
- `public boolean handleCharterClick(MenuOptionClicked event, Client client, ChatMessageManager chatMessageManager)`:
  - If `!enabled || unlocked`, return false.
  - Same NPC action check and NPC array lookup pattern as Primio.
  - If `npc != null && CHARTER_NPC_IDS.contains(npc.getId())`, consume event and send lore-friendly chat message. Use the format: `Color.RED, "Varlamore UIM:"` + `Color.WHITE, " The charter ship crew doesn't appear to be taking passengers right now."` Return true.
  - This is a safety net — the RenderCallback hides the NPCs visually, but if a player somehow clicks where the NPC was (e.g., via menu entry), this catches it.

**Chat message pattern:**
- Follow the existing pattern from SpellTeleportBlocker/ItemTeleportBlocker: `ChatMessageBuilder` with `Color.RED` prefix and `Color.WHITE` body, queued as `ChatMessageType.GAMEMESSAGE`.
- For Primio: "The bird doesn't seem interested in interacting with you." (exact text per locked decision, no red prefix — this is meant to feel in-world, not like a plugin warning).

**Class annotations:** `@Slf4j` via Lombok. No `@Inject` annotations — this is a plain service class instantiated by the plugin (same pattern as SpellTeleportBlocker and ItemTeleportBlocker).

**Import order:** Follow project convention — javax.inject, com.google.inject, lombok, net.runelite.api, net.runelite.client, java.*

   - Register render callback: `renderCallbackManager.register(npcTransportBlocker.getRenderCallback());`

6. In `shutDown()`:
   - Unregister render callback: `renderCallbackManager.unregister(npcTransportBlocker.getRenderCallback());`

       {
           return;
       }
   }
