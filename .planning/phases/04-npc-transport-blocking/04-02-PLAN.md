**New method: `public void initClient(Client client, ClientThread clientThread)`**
- Store references. Called by plugin in startUp() after creating the blocker.
- This avoids @Inject (the class is manually instantiated, matching SpellTeleportBlocker pattern).

**New method: `public void createStandInNpcs()`**
- Called by plugin after login (on LOGGED_IN game state) and on startUp() if already logged in.
- If `unlocked`, do NOT create stand-ins (charter ships are visible).
- For each WorldPoint in DOCK_LOCATIONS:
  ```java
  clientThread.invoke(() -> {
      RuneLiteObject npcObject = client.createRuneLiteObject();

      NPCComposition comp = client.getNpcDefinition(MYSTERIOUS_OLD_MAN_NPC_ID);
      int[] modelIds = comp.getModels();
      short[] recolFrom = comp.getColorToReplace();
      short[] recolTo = comp.getColorToReplaceWith();

      ModelData[] mds = new ModelData[modelIds.length];
      for (int i = 0; i < modelIds.length; i++)
      {
          ModelData md = client.loadModelData(modelIds[i]);
          if (md == null) continue;
          md.cloneColors().cloneVertices();
          if (recolFrom != null && recolTo != null)
          {
              for (int j = 0; j < recolFrom.length; j++)
              {
                  md.recolor(recolFrom[j], recolTo[j]);
              }
          }
          mds[i] = md;
      }

      // Filter out nulls from mds array before merging
      ModelData[] filtered = java.util.Arrays.stream(mds)
          .filter(java.util.Objects::nonNull)
          .toArray(ModelData[]::new);
      if (filtered.length == 0) {
          log.warn("Failed to load Mysterious Old Man model data");
          return;
      }

      Model model = client.mergeModels(filtered).light();
      npcObject.setModel(model);

      Animation idle = client.loadAnimation(comp.getStandingAnimationID());
      npcObject.setAnimation(idle);
      npcObject.setShouldLoop(true);
      npcObject.setRadius(60);

      LocalPoint lp = LocalPoint.fromWorld(client.getTopLevelWorldView(), dockLocation);
      if (lp != null)
      {
          npcObject.setLocation(lp, 0);
          npcObject.setActive(true);
          standInNpcs.add(npcObject);
          log.debug("Spawned Mysterious Old Man stand-in at {}", dockLocation);
      }
      else
      {
          log.debug("Dock location {} not in current scene, skipping stand-in", dockLocation);
      }
  });
  ```
- Note: `dockLocation` is the loop variable iterating over DOCK_LOCATIONS. Use a local final copy for the lambda.

**New method: `public void destroyStandInNpcs()`**
- Called on logout, shutdown, or when unlocked state changes to true.
- For each RuneLiteObject in standInNpcs: `npcObject.setActive(false);`
- Clear the list: `standInNpcs.clear();`

**New method: `public void handlePostMenuSort(PostMenuSort event, Client client)`**
- If `!enabled || unlocked || standInNpcs.isEmpty()`, return.
- Get the selected scene tile: `Tile tile = client.getTopLevelWorldView().getSelectedSceneTile();`
- If `tile == null`, return.
- For each RuneLiteObject in standInNpcs:
  - If `npcObject.isActive() && npcObject.getLocation() != null && npcObject.getLocation().equals(tile.getLocalLocation())`:
    - Inject a menu entry:
      ```java
      client.getMenu().createMenuEntry(1)
          .setOption("Talk-to")
          .setTarget("<col=ffff00>Mysterious Old Man</col>")
          .setType(MenuAction.RUNELITE)
          .onClick(ev -> sendStandInMessage(chatMessageManager));
      ```
    - Break after first match (only one stand-in per tile).
