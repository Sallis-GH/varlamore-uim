    Update VarlamoreUimPlugin.java to wire all components together with proper lifecycle management.

    Injected dependencies (add to existing):
    - @Inject private ClientToolbar clientToolbar (from net.runelite.client.ui.ClientToolbar)
    - @Inject private Injector injector (from com.google.inject.Injector) -- needed for panel instantiation

    Instance fields:
    - private VarlamoreUimPanel panel
    - private NavigationButton navButton (from net.runelite.client.ui.NavigationButton)
    - private BoundaryChecker boundaryChecker

    startUp() method:
    1. Initialize BoundaryChecker: `boundaryChecker = new BoundaryChecker(); boundaryChecker.loadRegions();`
    2. Log region count: `log.debug("Loaded {} Varlamore regions", boundaryChecker.getRegionCount());`
    3. Create panel: `panel = injector.getInstance(VarlamoreUimPanel.class);`
    4. Create NavigationButton:
       Use a programmatically generated placeholder icon (no file dependency):
       ```java
       final BufferedImage icon = new BufferedImage(16, 16, BufferedImage.TYPE_INT_ARGB);
       Graphics2D g = icon.createGraphics();
       g.setColor(new Color(0, 180, 120));
       g.fillRect(0, 0, 16, 16);
       g.dispose();
       ```
       Then build the NavigationButton:
       ```java
       navButton = NavigationButton.builder()
           .tooltip("Varlamore UIM")
           .icon(icon)
           .priority(5)
           .panel(panel)
           .build();
       ```
    5. Register nav button: `clientToolbar.addNavigation(navButton);`
    6. Log startup: `log.debug("Varlamore UIM plugin started");`

    shutDown() method (CRITICAL -- prevent memory leaks per research Pitfall 1):
    1. `clientToolbar.removeNavigation(navButton);` -- MUST match addNavigation
    2. `panel.resetStatus();`
    3. `panel = null;`
    4. `navButton = null;`
    5. `boundaryChecker = null;`
    6. Log shutdown: `log.debug("Varlamore UIM plugin stopped");`

    Event handlers:

    @Subscribe onGameTick(GameTick event):
    - First line: `if (!config.pluginEnabled()) return;` -- respect enable toggle (Pitfall 8)
    - Get player: `Player player = client.getLocalPlayer(); if (player == null) return;`
    - Check boundary: `boolean inVarlamore = boundaryChecker.isInVarlamore(player.getWorldLocation());`
    - Update panel: `panel.updateBoundaryStatus(inVarlamore);`
    - Do NOT log on every tick (Pitfall 6) -- only log.debug if boundary state CHANGES
    - Track previous state with a private boolean field `private boolean wasInVarlamore = true;`
    - Only log on state change: `if (inVarlamore != wasInVarlamore) { log.debug("Player boundary: {}", inVarlamore ? "inside" : "outside"); wasInVarlamore = inVarlamore; }`

    @Subscribe onGameStateChanged(GameStateChanged event):
    - If event.getGameState() == GameState.LOGIN_SCREEN or HOPPING: `panel.resetStatus();`
    - This ensures panel shows "Unknown" when not logged in

    Imports needed:
    - net.runelite.api.Player
    - net.runelite.api.events.GameTick
    - net.runelite.api.coords.WorldPoint
    - net.runelite.client.ui.ClientToolbar
    - net.runelite.client.ui.NavigationButton
    - com.google.inject.Injector
    - java.awt.image.BufferedImage
    - java.awt.Graphics2D
    - java.awt.Color

    Anti-patterns to avoid:
    - Do NOT forget shutDown() cleanup -- every add needs a remove
    - Do NOT log on every game tick -- only on boundary state changes
    - Do NOT skip the config.pluginEnabled() check in event handlers
    - Do NOT use log.info for routine boundary checks -- use log.debug
