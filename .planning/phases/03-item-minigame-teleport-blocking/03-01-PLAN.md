**Core logic in handleMenuClick:**
```java
public boolean handleMenuClick(MenuOptionClicked event, ChatMessageManager chatMessageManager, Client client)
{
    if (!event.isItemOp())
    {
        return false; // Not an item operation — skip (spells, walks, NPC clicks, minigame tab)
    }

    int itemId = event.getItemId();
    String option = event.getMenuOption();
    String itemName = event.getMenuTarget().replaceAll("<[^>]*>", "").trim();

    // Whitelist: Pendant of Ates — all destinations in Varlamore
    if (PENDANT_OF_ATES_IDS.contains(itemId))
    {
        return false;
    }

    // Block all-destination-blocked items
    if (BLOCKED_ITEM_IDS.contains(itemId) && isTeleportOption(option))
    {
        event.consume();
        sendBlockedMessage(itemName, itemId, chatMessageManager);
        log.debug("Blocked item teleport: '{}' (option: '{}')", itemName, option);
        return true;
    }

    return false;
}
```

**isTeleportOption helper:**
```java
private boolean isTeleportOption(String option)
{
    return TELEPORT_OPTIONS.contains(option) || option.contains("Teleport");
}
```

**Chat message format (per user decision — includes item name AND destination):**
```java
private void sendBlockedMessage(String itemName, int itemId, ChatMessageManager chatMessageManager)
{
    String destinations = ITEM_DESTINATION_DISPLAY.getOrDefault(itemId, "outside Varlamore");
    String message = new ChatMessageBuilder()
        .append(Color.RED, "Varlamore UIM:")
        .append(Color.WHITE, " " + itemName + " teleport to " + destinations + " is blocked — you are locked to Varlamore!")
        .build();

    chatMessageManager.queue(QueuedMessage.builder()
        .type(ChatMessageType.GAMEMESSAGE)
        .runeLiteFormattedMessage(message)
        .build());
}
```

The `getOrDefault(itemId, "outside Varlamore")` fallback ensures no crash if an ID is missing from the map, while still providing a meaningful message. The destination display for single-destination items (tablets) reads naturally: "Varrock Teleport teleport to Varrock is blocked". For multi-destination items: "Amulet of Glory teleport to Edgeville, Karamja, Draynor Village, Al Kharid is blocked".

   public void onMenuOptionClicked(MenuOptionClicked event)
   {
       if (!config.pluginEnabled())
       {
           return;
       }

       // Spell teleport blocking
       if (config.blockSpellTeleports())
       {
           if (spellTeleportBlocker.handleMenuClick(event, chatMessageManager, boundaryChecker))
