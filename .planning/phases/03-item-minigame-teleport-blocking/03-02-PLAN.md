Add public method for minigame teleport handling. This is called SEPARATELY from handleMenuClick because minigame tab teleports are NOT item ops (isItemOp() returns false):
```java
/**
 * Handle minigame grouping tab teleport attempts.
 * Called for non-item-op events that may be minigame tab clicks.
 * Minigame tab teleports use "Teleport" as the menu option with the minigame name as target.
 *
 * @return true if a minigame teleport was blocked
 */
public boolean handleMinigameTeleport(MenuOptionClicked event, ChatMessageManager chatMessageManager)
{
    // Minigame tab teleports have "Teleport" as the option
    if (!"Teleport".equals(event.getMenuOption()))
    {
        return false;
    }

    String target = event.getMenuTarget().replaceAll("<[^>]*>", "").trim();
    if (BLOCKED_MINIGAME_DESTINATIONS.contains(target))
    {
        event.consume();
        sendBlockedMinigameMessage(target, chatMessageManager);
        log.debug("Blocked minigame teleport to '{}'", target);
        return true;
    }

    return false;
}

private void sendBlockedMinigameMessage(String destination, ChatMessageManager chatMessageManager)
{
    String message = new ChatMessageBuilder()
        .append(Color.RED, "Varlamore UIM:")
        .append(Color.WHITE, " Minigame teleport to " + destination + " is blocked — you are locked to Varlamore!")
        .build();

    chatMessageManager.queue(QueuedMessage.builder()
        .type(ChatMessageType.GAMEMESSAGE)
        .runeLiteFormattedMessage(message)
        .build());
}
```

```java
@Subscribe
public void onMenuOptionClicked(MenuOptionClicked event)
{
    if (!config.pluginEnabled())
    {
        return;
    }

    // Spell teleport blocking
    if (config.blockSpellTeleports())
    {
        if (spellTeleportBlocker.handleMenuClick(event, chatMessageManager, boundaryChecker))
        {
            return;
        }
    }

    // Item teleport blocking
    if (config.blockItemTeleports())
    {
        if (itemTeleportBlocker.handleMenuClick(event, chatMessageManager, client))
        {
            return;
        }
    }

    // Minigame grouping tab teleport blocking
    if (config.blockMinigameTeleports())
    {
        itemTeleportBlocker.handleMinigameTeleport(event, chatMessageManager);
    }
}
```

Key design points:
- Minigame blocking is a separate config toggle from item blocking (per user decision — they are separate systems)
- handleMinigameTeleport is on ItemTeleportBlocker because it shares the same class and chat message utilities, but it's called independently with its own config guard
- The method chain short-circuits: spell -> item -> minigame. Each returns early if it handled the event.
- Minigame tab "Teleport" option won't conflict with spell or item blockers because:
  - SpellTeleportBlocker checks MenuAction == CC_OP on spellbook widgets
  - ItemTeleportBlocker checks isItemOp() which is false for minigame tab
